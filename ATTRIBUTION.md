# Icon attribution

The tab glyphs come from [game-icons.net](https://game-icons.net), licensed
under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). They are the
same set used by [The Guide · BRC 2026](https://the-guide-brc-2026.vercel.app),
so the two projects read as siblings.

Artwork has been modified: the solid background plate was removed and fills
changed to `currentColor`, so each glyph takes the ink or paper colour of
whatever it sits on.
